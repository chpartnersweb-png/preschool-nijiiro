# にじいろ LP 実装メモ

実装日：2026年10月28日

## 追加修正：全画面ヒーローとメニュー開閉

- ヒーローの固定最小高さ（740px／720px／680px）と最大高さを解除。
- `100vh`をフォールバックに、対応環境では`100dvh`で表示領域の高さに追従。PC・タブレット・スマートフォンで同じ基準を使用。
- 外周のbody余白とページ上端の角丸を取り除き、ヒーローが画面の端まで表示される構成に変更。
- 高さ600px以下では見出し・ロゴ・ボタン周辺をコンパクトにし、スクロールの補助表示を省略。
- メニューはGSAPで右からスライド表示し、背景をフェード、項目を順に表示。アイコンは二本線から閉じる印へ変化。
- 閉じるボタン、背景クリック、Escapeキー、メニュー内アンカーからの操作は、終了アニメーション後にdialogを閉じる。
- アンカー移動はメニューの終了を待ち、背景スクロールとフォーカスを復帰してから実行。
- 動きを減らす設定では開閉を即時切り替え。
- ユーザーの前回指定に従い、今回もビルド・テスト・ブラウザ表示／動作確認は未実施。

## 実装内容

- Astro初期ページを、プリスクール・学童 にじいろの日本語LPに置き換え。
- 生成イラストを全面に配置した、中央に短いコピーを置くヒーロー。
- PC用の横長画像とスマートフォン用の縦長画像を`picture`で切り替え。
- にじいろ紹介、プリスクール、学童、写真アルバム、スタッフ、教育方針、体験・アクセス。
- 支給写真13枚、支給ロゴ、支給キャラクター、favicon、OGPを使用。
- GSAPの初期表示・スクロールでの出現・PC装飾の視差。
- Lenisは1100px以上の精密ポインター環境、かつ動きを減らす設定でない場合に有効。スマートフォンのタッチスクロールは標準動作。
- ヒーローの紙飛行機の動きは短時間で静止。継続的な自動アニメーションは追加していない。
- ネイティブdialogのナビゲーションメニュー、Escapeで閉じる動作、キーボードフォーカス。
- スマートフォンの固定問い合わせリンクは、ヒーロー表示中・問い合わせ欄表示中に非表示。
- 電話・Instagram・住所検索へのリンク。
- 日本語title、description、favicon、OGPの参照。

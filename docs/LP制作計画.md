作成日：2026年10月28日

## 1. デザインの核

**「やってみたい」が、ひろがる世界。**

英語を教える施設という説明だけでなく、英語を通じて会話や遊び、新しい体験が広がる場所として紹介する。入口では子どもが興味を持つ楽しさ、本文では保護者が施設を理解できる具体性をつくる。

支給ロゴの虹色・丸い文字・ゾウをブランドの軸にする。支給写真にある絵本、工作、机を囲む会話などを、ページの内容と構図を決める根拠にする。

参考サイトの大きな主役、立体的な質感、画面の縁にかかる装飾、鮮やかな配色を手がかりに、にじいろ専用の構成へ置き換える。参考サイトのキャラクター、ロゴ、固有の背景・装飾画像は使用しない。

## 3. 色・文字・形

| 用途 | 色の案 | 使い方 |
| --- | --- | --- |
| 基本背景 | `#FFF8E8` | 読み物部分の温かい生成り色 |

| 学童 | `#E8F4FA` | 明るい空色の大きな面 |

色は実装時に支給ロゴと並べて調整し、文字と背景のコントラストを確認する。本文を虹色にすることは避け、強調箇所を限定する。

見出しは丸みのある日本語書体、本文は可読性の高いゴシック体。候補はM PLUS Rounded 1cとNoto Sans JP。日本語の情報を主役にし、英語は補助見出しや装飾にとどめる。

本文16〜18px、行間1.85〜2.0、長文は1行あたり約30〜40文字を目安とする。PCでは見出しに余裕を持たせ、スマートフォンでは意味のまとまりを保って改行する。

境界は大きな弧や紙のような曲線を使い、細かな丸角カードの連続に頼らない。装飾は章の始まりと余白に集め、本文と重ねない。

## 4. ヒーロー

### 構図

画面全体に一つの立体的なイラストの世界を広げ、ロゴとコピーを中央の余白に配置する。左右にテキストと画像を分割しない。

```text
┌─────────────────────────────────────┐
│ 小さな教室ロゴ               メニュー │
│                                     │
│       英語が好きになる。              │
│       世界が広がる。                  │
│                                     │
│        虹・雲・絵本が広がる            │
│        立体的なイラストの世界          │
│   積み木                         工作 │
│                                     │
│       ［体験について問い合わせる］     │
└─────────────────────────────────────┘
```

ヒーロー内の情報は、名称が読めるロゴ、2行のコピー、問い合わせ導線に絞る。住所・電話番号・教育方針・実績数字・長い補足は後続へ配置する。

PCはおおむね1画面。スマートフォンはブラウザUIを考慮した安定した高さを基準にし、コピー・イラストの主役・ボタンが重ならないように調整する。小さな画面では必要に応じて自然に高さを伸ばす。

### 生成画像

写真風の架空の教室や子どもは生成しない。虹、絵本、積み木、工作の紙などで構成する、明らかにイラストと分かる情景を生成する。実際の施設にあるか分からない園庭・園舎・設備は描かない。

- 主画像：横長の立体イラスト1点。中央上部にコピー用の静かな余白を設ける。
- モバイル用：同じ画風・色・モチーフで縦長構図を制作。横長の単純な中央切り抜きだけに依存しない。
- 独立装飾：必要な場合に限り、同じ質感の絵本、積み木、雲を透明背景で個別生成する。
- 単純な弧、波線、点、星の輪郭はSVG/CSSで制作する。
- ロゴとコピーはHTML・支給画像として配置し、生成画像に焼き込まない。
- ゾウは支給ロゴ／小さなキャラクターで登場させる。新しい別キャラクターは追加しない。

**主画像の生成指示案**

> プリスクール・学童のWebサイト用の横長メインイラスト。英語を通して遊びや会話、新しい世界が広がることを表現する。虹、開いた絵本、丸い積み木、工作の紙を、やわらかな立体の紙工作とマットな粘土の質感で描く。支給ブランドと調和するピンク、黄色、緑、空色を使い、背景は淡い生成り色。中央上部には濃い色の日本語コピーを重ねられる低密度で均一な余白を広く残し、モチーフは下半分と周辺に配置する。正面から一つの世界を眺める構図。温かく明るい光。文字、ロゴ、透かし、人物、建物は含めない。左右二分割の広告構図にしない。特定作品のキャラクターや固有の装飾を再現しない。

生成後は、余白・切り抜き・質感・スマートフォンでの構図を確認し、採用した画像と生成指示をプロジェクト内に保存する。生成情景と実際の教室写真の役割を混同しない。

## 5. ページ構成

### 01 入口：英語が好きになる。世界が広がる。

前項のヒーロー。固定ヘッダーにはコンパクトなロゴとナビゲーションを設置する。スマートフォンのメニューは「にじいろについて」「プリスクール」「学童」「スタッフ」「体験・アクセス」を基本とする。

### 02 にじいろについて：「やってみたい」を大切に。

大きな短い見出しの周りに、読み聞かせ・会話・活動の写真を余白を残して配置する。中央の文章は次の趣旨を3〜4行で伝え、必要な説明をその下に置く。

「遊んで、話して、やってみる。毎日の中で英語に触れながら、一人ひとりの『できた！』を育てます。」

幼児期から放課後へ続く二つの入口を文字リンクで示す。この段階では対象年齢や対象学年の範囲を断定しない。

### 03 プリスクール：遊びの中で、英語が身近になる。

ミント色の大きな弧の中に読み聞かせの主写真を置き、周囲に制作・机を囲む活動の写真を添える。英語中心の保育と、生活の中で英語に触れる方針を説明する。

四つの成長のきっかけはカードにせず、絵本の余白に書き添えるように配置する。

- 表現や語彙が増える → 話す楽しさへ。
- 英語が伝わる → 「伝わった！」という自信へ。
- 相手の反応を待つ → 思いやる気持ちへ。
- 初めての言葉に出会う → 新しい興味へ。

成長を保証する表現は使わず、教室が大切にする関わり方として記述する。章末に体験入園の問い合わせリンクを置く。

### 04 学童：放課後に、英語と仲良くなる。

空色の背景に、ノートを開いたような横長の構成をつくる。会話・活動・制作の写真を長方形で組み、プリスクールとは異なる少し落ち着いたリズムにする。スマートフォンは縦に読み進める。

「遊び・会話・活動を通して、英語への抵抗感をやわらげ、もっと話してみたい気持ちを育てる」を主題にする。ご提供の四つの関わりと成長を、短い文章で丁寧に伝える。

写真に写る子どもの年齢や在籍コースは画像だけから確定できない。コース専用の写真と確認できるまでは、教室共通の活動風景として扱う。章末に体験学童の問い合わせリンクを置く。

### 05 にじいろの日々：教室の外にも、出会いがある。

教室内の写真が続いた後に、お出かけ・屋外での活動・ステージの写真で画面を広げる。大小の写真を組むアルバム構成にし、PCもスマートフォンも縦方向で閲覧できるようにする。

写真だけでイベント名、開催頻度、年間行事、参加条件、送迎の有無などは判断しない。キャプションは見て分かる内容、または確認できた事実に限定する。

最後にInstagramへの通常リンクを置く。Instagramの投稿埋め込みは初期実装の必須要件にせず、ページを軽く保つ。

### 06 スタッフ：いろいろな経験が、一人ひとりの力になる。

園長のメッセージを少し大きく取り、その下にスタッフ3名の紹介を余白のある段違いの文章組みで配置する。同じサイズの人物カードを4枚並べる構成にはしない。

- 奥山豊（アレックス）園長：海外生活15年、20年以上の英語指導経験。生活に根ざした英語。
- マミ先生：米国アラバマ大学芸術学科卒業。日常の自然な英語コミュニケーション。
- エミリー先生：フランス出身。アメリカでの生活、日本での子育て経験。文化を越えた関わり。
- マナ先生：東京での長年の保育施設勤務。英語と制作活動。

日本人・外国人スタッフ、外国人ボランティアが関わる環境も伝える。活動写真の人物を名前と推定で対応させない。個人写真が未提供の場合は文章を主体とし、共通の活動写真を添える。

### 07 大切にしていること：「英語」だけではなく、「子ども」を見ています。

装飾を減らした生成り色の静かな章。大きな見出し、子どもと向き合う写真1枚、落ち着いた幅の本文で構成する。

日ごとの気持ちや体調、小さな変化に気づき、一人ひとりに寄り添う姿勢を伝える。「安心して過ごし、ここに来るのが楽しいと思える場所」を方針として言葉にする。

未提供の保護者レビュー、星評価、満足度、教育効果の数字は掲載しない。

### 08 体験・アクセス：まずは、にじいろを体験してください。

ヒーローの虹のモチーフを小さく再登場させ、ページの入口とつながる終わり方にする。

「体験入園・体験学童は、予約制で随時受付」を明記。体験料は不明なので「無料」とは記載しない。

問い合わせの主導線は、申込み方法が確定するまで電話を暫定案とする。ボタンは「体験について問い合わせる」、電話番号は `0166-67-2500` とし、`tel:0166672500` へ接続する。問い合わせボタンを押すだけで予約完了と誤解される表現は使わない。

## 7. GSAP・Lenisの演出設計

| 場所 | 演出 | 目安・目的 |
| --- | --- | --- |
| 初期表示 | コピーと主画像が短く現れ、周辺の絵本・積み木が少し遅れて入る | 全体0.8〜1.2秒程度。ローディング待ちを演出しない |
| ヒーロー | 周辺の独立装飾のみ、ゆっくり小さく浮く | 画面外では停止。5秒以内で静止、または継続演出に停止操作を用意 |
| 導入 | 写真が小さな位置差・回転差を伴って順に現れる | 0.5〜0.7秒、間隔0.08〜0.12秒程度 |
| コースの章 | 背景の弧・章見出し・写真が順に入る | 読む順番を示す。本文全体を長く待たせない |
| PCの背景装飾 | スクロールに対してゆっくり位置が変わる | 12〜24px程度。本文やボタンは安定させる |
| スタッフ | 名前・紹介が短くフェード表示 | 経歴を読むことを優先 |
| ボタン | hover・focusで小さく持ち上がる | 2〜4px程度。クリック範囲は移動させすぎない |

GSAP ScrollTriggerで画面内への進入を制御する。LenisはPCで控えめな慣性を与え、公式の連携方法に沿ってGSAPのtickerと同期する。独立したアニメーションループを二重に回さない。

スマートフォンは通常のタッチスクロールを優先し、スクロールに追随する大きな移動や固定演出を減らす。章を読むためにスクロールを何画面分も拘束する構成、強制的な横移動は採用しない。

`prefers-reduced-motion: reduce`ではLenisの慣性、浮遊、視差、バウンドを停止し、内容をそのまま表示する。アニメーション初期化が失敗しても情報が隠れたままにならない構成にする。

メニュー表示中は背景スクロールを適切に止め、閉じると復帰する。キーボード操作、フォーカス、Escapeでの閉鎖、アンカー位置と固定ヘッダーの干渉も実装時に確認する。

## 8. レスポンシブ

- 1100px以上：中央に広がるヒーロー、余白のある写真配置、コースごとに異なる大きな構図。
- 768〜1099px：写真の重なりを減らし、装飾数と移動量を削減。必要に応じてナビをメニューにまとめる。
- 767px以下：ヒーローを縦長専用構図へ。文章と写真の順序を保った1列構成。横スクロールを前提にしない。
- スマートフォン下部に「体験について問い合わせる」の固定ボタンを配置。電話番号・受付時間を見せる問い合わせ欄へ移動し、そこから電話できるようにする。
- 固定ボタンの高さとsafe-area分を本文末尾に確保。最後の問い合わせ欄と重なる場合は固定ボタンを非表示にする。
- 操作対象は44px以上を目安とし、装飾がリンクや文字を覆わないようにする。

## 9. 実装方針

Astroの静的ページを軸に、章ごとにコンポーネントを分ける。電話番号・住所・受付時間などは共通データに集約する。GSAPとLenisをまとめたモーション処理を用意し、画面幅と動きを減らす設定に応じて初期化・解除する。

画像は画面幅に応じた適切なサイズとWebP/AVIF等を検討し、ヒーローを優先読み込み、下部の活動写真は遅延読み込みする。幅と高さを指定してレイアウトのずれを抑える。

`lang="ja"`、ページタイトル、description、支給OGP、支給faviconを設定する。公開URL未定のためcanonicalやOGPの絶対URLは公開先確定後に設定し、仮ドメインを確定情報として出力しない。

実装時は対象ルートを再確認する。開発サーバーが必要な場合は、AGENTS.mdの指示に沿って `astro dev --background` を使用する。

## 11. 制作の順序と確認項目

1. ヒーローの横長・縦長構図と必要な独立装飾を生成し、支給ロゴとの調和を確認。
2. ヒーロー、導入、プリスクール、学童までを同じデザインルールで組み、画面のリズムを確立。
3. アルバム、スタッフ、教育方針、問い合わせ・アクセスを制作。
4. GSAP・Lenisを加え、モバイルと動きを減らす設定を調整。
5. ビルドとPC・スマートフォンでの表示、電話・Instagram・アンカー・メニュー、固定ボタンと本文の重なり、画像読み込みを確認。
